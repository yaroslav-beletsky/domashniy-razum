# UI-спека: референс yandex.ru/iot + Gravity UI

Референс — публичная (разлогиненная) страница `https://yandex.ru/iot/`, снята 2026-11-08,
headless Chrome, desktop 1440×900 и mobile 390×844. Это лендинг-обёртка того же веб-приложения
«Умный дом с Алисой»: CSS-переменные в разметке — полноценная токен-система самого приложения
(в ней есть device-card, sensor-card, switcher, tab-bar), поэтому токены валидны и для
будущей админки. Залогиненный вид с карточками устройств недоступен без аккаунта — отмечено
в «Спорных местах».

Скриншоты: `shots-ui/yandex-iot-desktop-1440.png`, `shots-ui/yandex-iot-desktop-1440-full.png`,
`shots-ui/yandex-iot-mobile-390.png`, `shots-ui/yandex-iot-mobile-390-full.png`,
`shots-ui/gravity-ui-demo-light.png`, `shots-ui/gravity-ui-demo-dark.png`.
Полный дамп 257 CSS-переменных: `docs/ui-yandex-tokens-raw.txt`.

### Типографика

- Семейство: **YS Text** (registered как `YS Text regular/medium/bold/light` + variable `400–700`,
  woff2 c `yastatic.net`), fallback `system-ui, Arial, sans-serif`. Корень `16px`.
- Шкала (классы `typography_*` с референса):

| Класс | Размер/интерлиньяж | Вес | Где |
|---|---|---|---|
| `text-13-r` | 13/16 | 400 | подписи под заголовком карточки |
| `text-14-r` | 14/20 | 400 | основной текст |
| `text-14-m` | 14/20 | 500 | кнопки, ссылки-действия |
| `text-16-m` | 16/20 | 500 | заголовок карточки |
| `text-1` | 18/24 | 500 | навбар, мелкие заголовки |
| `title-24-b` | 24/28 | 700 | заголовки секций (h1/h2) |

### Скругления, тени, отступы

- Радиусы: карточки/иконки-контейнеры **14px**, кнопки-«пилюли» и крупные карточки **16px**.
- Тени: маленькая `0 2px 6px rgba(0,32,80,.04)` (`--shadows_box-shadow-style: 0 0.125rem 0.375rem #0020800a`),
  «плавающая» `0 4px 24px rgba(0,32,128,.12)` (`--shadows_floating-shadow-style: 0 0.25rem 1.5rem #0020801f`).
  Основа теней — синий оттенок `#002080`, не чёрный.
- Отступы: боковой паддинг страницы **16px** (`--horizontal-wrapper-padding: 1rem`), паддинг навбара
  `8px 8px 8px 16px` с gap 12px, карточки `padding 12–16px`, секции разнесены на 12–20px.
  Все расстояния в rem при корне 16px (мобильная масштабируемость).

### Ключевые компоненты «как у Яндекса»

- **Кнопка primary**: пилюля 16px, фон `#7a55ff`, текст белый `14/20` medium, паддинг `6px 12px`
  (высота 32px), press `#532ea5`, disabled `#c7ccd9`. Secondary: фон `#f2f3f5`, текст `#000c`.
- **Карточки**: белые, радиус 16, мягкая синеватая тень, заголовок 16 medium, подпись 13 regular
  `#919cb5`, иконка/фото сверху по центру. На мобильной сетке — 2 колонки.
- **Навигация**: минимальный навбар (`8/8/8/16`): слева пусто/лого, справа кнопка «Войти» (primary)
  + круглая иконка-кнопка настроек. В приложении — белый таб-бар `--home-tabbar__height: 3.125rem`.
- **Списки устройств**: белые карточки на сером фоне; переключатели (switcher): «ползунок» — круг
  `#fff` на дорожке, off-фон `#afb9cc` (`--other-components_switcher_off-bg`), on — акцент;
  чипы-фильтры: активный `#7a55ff`, неактивный `#f2f3f5` (`--buttons_chip-button_*`).
- **Инпуты**: заливка `#f2f3f5`, рамка `#c7ccd9`, без тени.
- **Hero/медиа-плитки**: фото + градиент `linear-gradient(rgba(0,0,0,.3) 0–10%, transparent 70%)`,
  текст белый поверх.

## 2. Gravity UI: проверка пригодности

Проверено установкой и рендером (скрины `shots-ui/gravity-ui-demo-{light,dark}.png`):

- **`@gravity-ui/uikit` 8.0.0** — peer `react ^18 || ^19` → совместим с панелью (React 19.1, Next 15.5,
  Tailwind 4). 75 групп компонентов: Button, Card, Switch, Select, Checkbox/Radio/Slider, Modal,
  Drawer/Sheet, Toaster, Skeleton, Tabs (в v8 — композиция `TabProvider`+`TabList`+`Tab`, старого
  `<Tabs items=...>` больше нет), мобильные примитивы (`components/mobile`).
- **`@gravity-ui/icons` 2.23.1** — 811 иконок, peer `react *`.
- **Темы есть из коробки**: `ThemeProvider theme="light|dark"` вешает `.g-root_theme_light|_dark`;
  тёмная — `rgb(34,29,34)` фон, читается полностью (проверено рендером).

### Насколько близко к yandex.ru/iot «из коробки»

Жанр тот же (светло-серый фон, белые карточки, пилюли, круглые свитчи), но дефолты другие:
бренд — **жёлтый** `rgb(255,190,92)`, шрифт — **Inter**, радиусы 3–10px, тексты по 13/15px.
«Ровно как у Яндекса» без overrides не будет.

### Что перекрыть, чтобы сошлось с референсом

Гравити целиком на CSS-переменных — точная подгонка делается одним слоем overrides на `.g-root`:

```css
.g-root {
  --g-color-base-brand: #7a55ff;
  --g-color-base-brand-hover: #6a45f5;      /* между 7a55ff и pressed */
  --g-color-text-brand: #7a55ff;
  --g-color-base-background: #f2f3f5;
  --g-border-radius-l: 14px;
  --g-border-radius-xl: 16px;
  --g-font-family-sans: 'YS Text', Inter, system-ui, Arial, sans-serif;
  --g-color-text-primary: rgba(0, 0, 0, 0.8);
  --g-color-text-secondary: #919cb5;
  --g-color-line: #e2e4eb;
}
/* тёмная тема: фон ~#1f1f23, карточки #2c2c30, акцент тот же #7a55ff */
```

### Чего не хватит «из коробки»

1. **Шрифт YS Text** — проприетарный; файлы лежат на `yastatic.net`, но лицензии на переиспользование
   нет. Безопасно: остаться на Inter (близка по пропорциям) или купить/найти замену.
2. **Точная карточка устройства** (иконка-плитка 14px + заголовок 16 medium + подпись 13 + свитч
   справа) — собирать из `Card`+`Switch` самому, это ~30 строк.
3. Пастельная палитра сценариев и градиенты — завести как свои токены рядом.
4. Чипы-фильтры активные фиолетовые — `Label`/`Button view="flat"` + override, готового «chip-button» нет.

### Риски

- v8 uikit — свежий мажор: API табов/мобильных примитивов менялся между версиями; часть гайдов в
  интернете по v5–v7. Лечится фиксацией версии в `package.json` (без `^`).
- Глобальные дефолты Gravity (`box-sizing`, фокус-ринг) могут конфликтовать с остатками shadcn —
  миграцию делать «с заменой», а не «рядом».
- Торговый образ Яндекса (фиолетовый Алисы + YS Text вместе) — ок для внутренней админки, для
  публичного продукта prudent-проверка у юристов.

## 3. Рекомендация

**Брать Gravity UI как базу + слой токен-overrides под референс** (вариант «А»).

- Пакеты: `@gravity-ui/uikit@8` + `@gravity-ui/icons@2`, peer-совместимы с React 19/Next 15.
- Даёт из коробки: тёмную тему, все контролы, тосты, модалки, скелетоны, иконки, мобильные
  примитивы — то, чего у shadcn-обёртки нет и что пришлось бы писать.
- Точная «яндексовость» достигается overrides-слоем из раздела 2 (один CSS-файл) + локальные
  компоненты карточки устройства/чипов поверх `Card`.
- Альтернатива «Б» (только токены в Tailwind 4, без Gravity) даст пиксельную точность быстрее, но
  вернёт необходимость вручную держать тёмную тему, контролы и доступность — дороже в поддержке.
  Если владельцу важен только «выглядит как Яндекс» и точность каждого пикселя — «Б»; если важны
  темп и тёмная тема — «А».

## Спорные места (чтобы владелец знал)

1. Референс — **разлогиненный лендинг**; карточки устройств/тумблеры видны только в приложении
   под аккаунтом. Токен-система в CSS общая, но скриншотов залогиненного вида нет.
2. `iot.yandex.ru` не резолвится извне (DNS) — приложение живёт внутри `yandex.ru`, глубокие
   под-страницы раздела без логина недоступны.
3. YS Text не лицензирован — «ровно как у Яндекса» со шрифтом законно не выйдет; предложить Inter.
4. Дефолт Gravity UI — жёлтый бренд (наследие Яндекса-поиска), не фиолетовый Алисы; без
   overrides-слоя вид будет «яндексовский, но не iot».
