# station-ready.sh — инструкция

## Что это

Один скрипт, который берёт **ЛЮБУЮ** Яндекс Станцию (Мини, Станция 2, …) и доводит до состояния «готова к панели». После скрипта колонку просто добавляешь в панель — всё остальное уже сделано.

Скрипт идемпотентен: если запустить повторно, сделает только то, чего ещё нет.

## Нужно

- Mac с `adb` (`brew install android-platform-tools`)
- Стенд `lite-kit` поднят на `192.168.88.23`: `equasar_server.py`, порты 80/443
- DNS: `quasar.yandex.net`, `quasar.yandex.ru`, `scbh.yandex.net` → `192.168.88.23`
- Ключ LiteLLM в `LITELLM_API_KEY` (env или `~/.station-ready.env`)

## Запуск

```bash
cd ~/Documents/home/station-llm

# если ключ не в env:
export LITELLM_API_KEY=sk-...

# запуск:
./station-ready.sh
```

## Что делает скрипт (8 шагов)

| Шаг | Что | Ты |
|---|---|---|
| 0 | Проверяет стенд, DNS, прошивки | Ничего |
| 1 | Инструкция: сбрось колонку | **Enter** |
| 2 | Инструкция: дай Wi-Fi | **Enter** |
| 3 | Ждёт колонку на стенде (`/recent_clients`) | Ничего |
| 4 | Ждёт OTA (колонка сама ставит прошивку) | Ничего |
| 5 | Проверяет ADB + root | Ничего |
| 6 | Защита: noupdate, маркеры, патч cfg, DoH, S98 | Ничего |
| 7 | Ставит мост quasar-bridge + голос `ermil` | Ничего |
| 8 | Пишет: «Готово» — IP, MAC, модель | Забрать в панель |

**Ручных действий ровно два:** сброс (Enter) и Wi-Fi (Enter). Остальное — автоматика.

## Что в итоге

После скрипта колонка:

- На уязвимой прошивке (та, что отдаёт стенд)
- ADB по сети (порт 5555), root
- Обновления заблокированы (`yandex-noupdate.sh`)
- Доступ защищён (маркеры `+i`, `quasar.cfg` патчен, DoH заблокирован, `S98adbd` в автозапуске)
- Мост `quasar-bridge` установлен, голос `ermil`
- `uniproxy` переключён на мост (`127.0.0.1:8443/uni.ws`)

Панель (`http://192.168.88.207:3110`) увидит готовую колонку — мастер пропустит шаги настройки.

## Как проверить

```bash
# ADB жив?
adb connect 192.168.88.X:5555
adb shell id          # uid=0(root) — root есть

# Мост healthy?
adb shell sh /data/opt/quasar-bridge/app/control.sh status
# → Bridge healthy (PID …)

# Обновления заблокированы?
adb shell sh /data/opt/yandex-noupdate.sh status

# Голос на месте?
adb shell cat /data/opt/quasar-bridge/tts.override
# → voice=ermil

# uniproxy на мост?
adb shell grep '127.0.0.1:8443/uni.ws' /system/vendor/quasar/quasar.cfg
# → (должно найтись)
```

## Откат

Сброс колонки к заводским стирает всё (`/data` очищается). Мост, маркеры, патчи — всё уходит. После сброса можно прогнать скрипт заново.

## Ограничения и риски

- **Стенд должен быть жив** всё время прогона (шаги 0–4). После шага 6 его можно гасить.
- **Станция 2** — окно adb короткое (~30-60 с после OTA). Скрипт ловит его агрессивным опросом (раз в 5 с), но если колонка долго ставит прошивку — может понадобиться повтор шага 4 (нажать Enter).
- **Сеть**: колонка должна получить DNS `192.168.88.35` от DHCP (или роутер должен форвардить quasar-домены на стенд). Скрипт проверяет DNS в шаге 0 и останавливается если не так.
- **`chattr`** может отсутствовать в busybox некоторых прошивок — тогда маркеры не защищены от удаления, но защита `quasar.cfg` всё равно работает.
